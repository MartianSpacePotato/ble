ESP32-S3 пульт

Несколько плат. BLE будит точку доступа, звук — после подключения телефона к её Wi‑Fi. Chrome / Edge / Android. На iPhone — Bluefy.

Этот браузер не умеет Web Bluetooth. Откройте страницу в Chrome или Edge на Android/ПК. Safari на iPhone не подходит — нужен Bluefy.
Общий лог

Страницу открывайте с http://localhost или https://. С диска (file://) Chrome блокирует Web Bluetooth. На компьютере: python -m http.server 8080 в папке со страницей. Одновременно телефон может слушать только одну SoftAP — зато BLE-команды идут на все подключённые платы.
